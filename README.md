# Splittrack

Run `npm ci` and `npm run dev`, then open http://localhost:3000. The local judging starter supports trips, members, equal or subset splits, balance explanations, duplicate and high-spend warnings, and manually recorded payments. Settlement suggestions are exact for up to eight nonzero balances. Select **Load five demo trips** to populate fictional bills and show category and payer insights. Local data is saved in `.triptrack-data.json`. Use fictional data.

See [the project plan](TRIPTRACK_PLAN.md) and [the database handoff](DATABASE_SETUP.md). Google sign-in, shared Supabase data, map pins, sponsorship, waivers, uploaded QR handling are planned.
